# Pear Music lyrics widget attribution

Metrofy's live lyrics home-screen widget is adapted from Pear Music by Dragonzord:
https://github.com/dragonzords/Pear-Music

The port retains Pear Music's AppWidget structure, two-page animated lyric transition,
word-progress highlighting, blurred artwork backdrop, and playback control behavior.
The Metrofy integration uses Metrofy's existing Media3 player, lyrics providers, Room
lyrics cache, and word-timestamp parser.
